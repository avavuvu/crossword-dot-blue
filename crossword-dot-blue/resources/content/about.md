# About

Crossword.blue is a free crossword repository created by Ava Dinh-Vu. It is similar to services like [crosshare.org](https://crosshare.org/).

There have been several different versions of the Crossword.blue site. It began as my personal crossword archive in 2024. You can find more about my work at [avavu.au](https://avavu.au)

It is free and open source. You can contribute to the code on the [Github](https://github.com/avavuvu/crossword-dot-blue).
